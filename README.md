# NHL24 Be a Pro — единая сборка R3

Русский лаунчер и исправления совместимости для NHL24 PC 0.8.3 / shadPS4.
Одна общая версия для всех компьютеров.

## Скачать обновление

[**NHL24-Unified-R3-update.zip**](releases/NHL24-Unified-R3-update.zip?raw=true)

Это обновление существующей полной папки NHL24-Be-a-Pro. Сама игра,
системные модули консоли, прошивка и ключи в репозиторий не входят.

1. Закрой игру и лаунчер.
2. Распакуй содержимое ZIP поверх своей существующей папки, заменив файлы.
3. Запусти NHL24Launcher.exe и проверь надпись «единая сборка R3».

В обновлении нет папки `user`; сохранения, настройки и путь к игре остаются
на месте. Для первого запуска требуется собственная настроенная полная
установка NHL24 PC и установленная игра. ZIP не является установщиком игры.

## Что изменено

- R3: обработка увеличившейся области памяти совместимого изображения.
  Исправление подготовлено по вылету `Unresolvable image overlap with equal
  memory address`, где описание поверхности менялось с 8,5 до 16 МиБ.
  Используется существующее пересоздание изображения с переносом содержимого.
- R2: последовательное копирование графических данных с ожиданием завершения.
  В отдельных сценах возможно снижение FPS.
- Сохранены исправления таблиц переходов в шейдерах и распределения памяти.
- Лаунчер сохраняет режим окна, разрешение вывода, VSync, FSR 1.0 и резкость RCAS.

FSR и RCAS не повышают внутреннее разрешение игры и не заменяют текстуры.

## Проверка и ограничения

Проверены исполняемый код обработки случая из лога, три других варианта роста,
32 несовместимых варианта, перенос 2 073 600 пикселей на RTX 4060 Ti и загрузка
игры. Сборка воспроизводится из исходного файла указанной версии.
Повтор исходного игрового момента на RTX 3070 и полный матч ещё требуют
проверки. Исправление не объявляется решением всех вылетов эмулятора.

При повторном вылете нужны свежие `launcher.log` и `user/log/shad_log.txt`,
модель видеокарты и описание последнего игрового момента. Перед публикацией
журналов проверь личные пути в них. Лаунчер ничего не отправляет автоматически.
